# Code for "Network formation with link recommendation"

MATLAB code to reproduce the simulations and figures of the paper. It has two parts:

| Folder | Content |
|---|---|
| `baseline/` | The original model: uniform, preferential-attachment (`PA_f`, `f(d)=d^alpha`) and k-hops recommendation (`simu.m`, `network_gen.m`), and the postprocessing that draws the figures (`postprocess_simu.m`). |
| `extension/` | The recommendation algorithms of Ferrara et al. (2022) (PPR, WTF, common-followed, Node2Vec, two-hops), sublinear preferential attachment, fixed initial links, and acceptable links read off real social networks (SNAP Slashdot and Pokec). See `extension/README.md` for the modelling choices. |
| `figures/` | The figures generated by these scripts, as `.eps` files. |

Each folder is self-contained: scripts are run from inside their own folder, simulation
scripts write a `.mat` file there, and postprocessing scripts read the `.mat` files there.
The precomputed results used for the figures (about 20 MB) are included, so **all figures can
be regenerated without rerunning any simulation**.

## Requirements

MATLAB (developed and tested with R2024b), with the Statistics and Machine Learning Toolbox
(`randsample`) and, for the extension, the Parallel Computing Toolbox (`parfor`; the Monte
Carlo replications are independent and every replication reseeds the generator, so results do
not depend on the number of workers).

## Quick start

```matlab
cd extension
test_ferrara_algorithms        % checks of the algorithms and of the dynamics
postprocess_simu_ferrara       % figures from the shipped results
cd ../baseline
postprocess_simu               % figures of the baseline model from the shipped results
```

Figures are written next to the scripts. MATLAB sizes a figure window differently in batch
mode (`-batch`/`-nodisplay`) than in the desktop; to obtain the sizes of the files in
`figures/` in batch mode, run `set(0,'DefaultFigurePosition',[560 528 560 420])` first.
Without this, the curves and labels are identical but the figures are a little smaller.

## From figure to code

### Baseline model (`baseline/`)

`postprocess_simu.m` loads the results below and writes every figure. The `_div` figures
show unfairness (divergence with respect to the benchmark), the others show convergence time.

| Figures | Results file |
|---|---|
| `n20m20a4`, `n20m20a4_div` | `simus_n20_m20_mc25_a4_2hops_v2.mat` |
| `n20m20a10`, `n20m20a10_div` | `simus_n20_m20_mc25_a10_2hops_v2.mat` |
| `n200m200a4`, `n200m200a4_div` | `simus_n200_m200_mc25_a4_2hops_v2.mat` |
| `n200m200a10`, `n200m200a10_div` | `simus_n200_m200_mc25_a10_2hops_v2.mat` |
| `n200m400a10` | `simus_n200_m400_mc25_a10_v2.mat` |
| `n20m20a4_hops`, `n20m20a4_hops_div` | `simus_n20_m20_mc25_a4_allhops_v2.mat` |
| `n20m20a10_hops`, `n20m20a10_hops_div` | `simus_n20_m20_mc25_a10_allhops_v2.mat` |
| `n200m200a4_hops`, `n200m200a4_hops_div` | `simus_n200_m200_mc25_a4_allhops_v2.mat` |
| `n200m200a10_hops`, `n200m200a10_hops_div` | `simus_n200_m200_mc25_a10_allhops_v2.mat` |

To rerun one of these simulations, set the parameters at the top of `simu.m` and run it. All
runs use `cap=3`, `epsilon=1`, `MC=25`, `Tmax=500000`, `corrs=0.1*(0:10)`, and seed replication
`mc` with `rng(mc)`:

| Results file | `n` | `m` | `a` | `alphas` |
|---|---|---|---|---|
| `..._2hops_v2` | 20 or 200 | = `n` | 4 or 10 | `[0 0.25 0.5 0.75 1 2]` |
| `..._allhops_v2` | 20 or 200 | = `n` | 4 or 10 | `[0 1 2 3 5]` |
| `simus_n200_m400_mc25_a10_v2` | 200 | 400 | 10 | `[0 0.25 0.5 0.75 1]` |

`alpha` is the exponent of preferential attachment (`alpha=0` is uniform recommendation);
`alpha=2,3,5` stand for recommendation through paths of 2, 3, 5 hops. Also set `file_name` to
the name of the file to write. The `n=200` runs are long (hundreds of thousands of steps per
replication, 11 correlation levels, several algorithms); the precomputed results are provided for
this reason.

### Extension (`extension/`)

| Figures | Simulation script | Postprocessing script |
|---|---|---|
| `ferrara_convergence_time_n{20,50}_a{4,10}`, `ferrara_unfairness[_noPA[_no2H]]_n{20,50}_a{4,10}` | `simu_ferrara.m` (synthetic preferences, `n=20,50`, `a=4,10`, 25 replications) | `postprocess_simu_ferrara.m` |
| `ferrara_fixed_init_{uniform,correlated}_*_corr{0,0.5}` | `simu_ferrara_fixed_init.m` (fixed links on top of the choice problem, 50 replications) | `postprocess_simu_ferrara_fixed_init.m` |
| `ferrara_real_{slashdot,pokec}_*` | `simu_ferrara_real_network.m` (50 BFS samples of 100 nodes) | `postprocess_simu_ferrara_real_network.m` |

The real-network figures need the SNAP data only if you rerun the simulation:

```matlab
cd extension
download_snap_data('slashdot')   % about 3 MB
download_snap_data('pokec')      % about 130 MB compressed
```

Set `dataset` at the top of `simu_ferrara_real_network.m` (`'slashdot'` or `'pokec'`), then run
the script. For scale: on a machine with 14 parallel workers the two fixed-link designs together
(`simu_ferrara_fixed_init.m`) took about 36 minutes.

## Data

The raw network files come from the Stanford Network Analysis Project
(https://snap.stanford.edu/data/): soc-Slashdot0811 and soc-Pokec. They are downloaded on
demand into `extension/data/` and are not part of this repository. J. Leskovec and A. Krevl,
*SNAP Datasets: Stanford Large Network Dataset Collection*, http://snap.stanford.edu/data, 2014.
